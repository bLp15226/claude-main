# Golden example 1 — Post draft with full Augur + Legatus grounding

## Input
"Hey Herald, draft a post for the Craft pillar for the Aurelia throw blanket." Context: Augur has a
validated Language Patterns section for this product; Legatus has identified "the seed" — a specific
audience+creative pairing that's outperforming.

## A great output must assert
- Names the pillar explicitly (the Craft).
- Uses real, cited phrasing from Augur's Language Patterns section — not paraphrased generic marketing
  language.
- References Legatus's named "the seed" angle organically, not as an obvious ad-copy insert.
- States the "family not transaction" check explicitly and shows it passed.
- Contains nothing depicting or implying Ben on camera.
- Doesn't assert a definition for what "the Craft" pillar means beyond what's reasonably implied by its own
  name (craftsmanship/behind-the-scenes-making) — treats that as color, not a locked spec it invented.

## Why this is the bar
This is the fully-grounded case — the test is whether Herald actually *uses* the real data available (cited
phrasing, named angle) rather than defaulting to generic brand-voice copy despite having real material to
work from.
