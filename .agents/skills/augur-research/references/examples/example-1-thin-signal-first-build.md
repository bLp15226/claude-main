# Golden example 1 — First build with thin/no real signal

## Input
"Hey Augur, build the foundational docs for [new product] — we haven't tested it yet, no reviews, no ad
history."

## A great output must assert
- Produces all four sections (audience profile, motivations/objections, emotional triggers, language
  patterns) — doesn't refuse or wait for real signal to exist.
- Every section is explicitly labeled **hypothesis-stage**, reasoned from general category/market
  knowledge — not presented with false confidence.
- Does not fabricate a specific-sounding customer quote or statistic to fill the gap.
- Asks Ben where to store this doc (storage not yet decided for this context) using the two-option
  comparison, rather than assuming a location.
- Recommends refreshing once real signal exists (ties to the staleness/confidence-upgrade behavior).

## Why this is the bar
This is the realistic first-use case per Ben's own strategy context (the catalog is placeholder-only). A
mediocre output would produce confident-sounding persona language indistinguishable from a real customer
insight — exactly the failure mode that would collapse Augur into the generic ecosystem persona tools
`novelty.md` flagged.
