# Golden example 1 — Password/coming-soon page build

## Input
"Build the password/coming-soon page — black-and-gold, sealed envelope visual with a subtle hover/pulse on
the wax seal, plus an email capture field. CSS/SVG only, must load fast on mobile." (Real task from the
rebuild brief's build order #1.)

## A great output must assert
- Reads the current theme's password-page template first and states what was found (existing content,
  whether a password page template already exists).
- Packages CSS/SVG-only code — no video, no JS complexity — matching the "whisper version" scope explicitly
  called out in the rebuild brief (this is not the full envelope-opening animation).
- Names a real Shopify file path (e.g. `templates/password.json` or `.liquid`, per
  `references/shopify-theme-structure.md`).
- States the exact operation (replace/insert/append) for each file touched.
- Updates the paste-status tracker to `generated` for this file.

## Why this is the bar
This is a real, near-term task from the actual rebuild brief. A mediocre output would either skip the
read-first step, produce vague "add this to your password page" instructions, or over-build (adding video/
JS complexity the brief explicitly scoped out for this specific page).
